# Iqra Rafiq - Portfolio Website

A personal portfolio website for Iqra Rafiq, showcasing skills, services, and an interactive "about me" section.

## Features
*   **Fully Responsive Design:** Adapts smoothly to desktop, tablet, and mobile screen sizes.
*   **Interactive Navigation:** A responsive hamburger menu for mobile users.
*   **Dynamic Typing Animation:** Uses Typed.js to cycle through professional roles.
*   **Smooth Scrolling & Animations:** Custom CSS animations and smooth scrolling for a better user experience.
*   **Contact Form & Social Links:** Easy ways to get in touch.

## Technologies Used
*   **HTML5**
*   **CSS3** (Custom Properties, Flexbox, CSS Grid, Media Queries)
*   **Vanilla JavaScript**
*   **FontAwesome 6** (Icons)
*   **Typed.js** (Typing effect)

## How to View
To view the portfolio locally, you do not need any build tools or web servers. Simply download or clone the repository and open the `index.html` file in any modern web browser.
